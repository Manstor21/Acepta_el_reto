# Acepta el Reto

Resolución diaria de problemas de [¡Acepta el reto!](https://aceptaelreto.com), el juez de programación en línea de la Universidad de Valladolid.

## Estructura

Cada problema se organiza en su propia carpeta dentro del volumen que le corresponde:

```
001-100/
  100.Nombre del problema/
  101.Nombre del problema/
101-200/
  ...
```

## Progreso

| Volumen | Rango | Resueltos |
|---------|-------|-----------|
| 1 | 100-199 | 35/100 |

## Como ejecutar

```bash

# Ejecutar
java Problema < entrada.txt
```
